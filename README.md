# 请求观测台

纯原生实现（无框架）的 HTTP 请求调试台：发起请求、自动重试、退避抖动、超时中断、缓存/占位降级、Canvas 请求时序可视化。

## 技术栈

- **Fetch + AbortController**：请求、超时中断、取消
- **Web Worker**：请求引擎运行在 Worker 中，并发任务按 id 隔离；页面卸载时终止 Worker
- **IndexedDB**：成功响应缓存（带 TTL）+ 请求历史持久化（Worker 与主线程共用 `js/db.js`）
- **Canvas**：请求时序图（尝试段 + 退避等待段）

## 运行

```bash
# 1) 异常链路 mock 服务器（零依赖，Node）
node mock-server.js            # http://localhost:8787

# 2) 静态服务（ES module + module worker 需通过 http 访问）
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 功能

- 可配置：重试次数、退避策略（固定/线性/指数）、基础延迟、延迟上限、full jitter 抖动、超时、缓存 TTL
- 每次尝试独立展示：类型（成功/HTTP 错误/超时/网络错误/取消）、HTTP 状态码、耗时
- 重试次数上限生效后按序降级：**新鲜缓存 → 过期缓存/无缓存则返回占位数据**
- Canvas 时序图按真实墙上时间绘制每次尝试与退避等待段
- 单条取消、取消全部、清空历史与缓存
- 历史刷新页面后仍可查
- `pagehide` 时取消全部请求并终止 Worker

## 异常链路验证

| 场景 | 操作 |
| --- | --- |
| HTTP 错误 | 请求 `/error`（500）或 `/notfound`（404），看重试与上限 |
| 请求超时 | 请求 `/slow?ms=5000`，超时设为 1000ms |
| 网络中断 | 请求后断开网络，或直接请求一个不可达地址（如 `http://localhost:9/`） |
| 退避抖动 | 请求 `/flaky?force=500` 或 `/error`，时序图中黄色斜纹段为抖动等待 |
| 缓存降级 | 先请求 `/ok` 成功写缓存，再请求 `/error`（重试耗尽）→ 命中缓存 |
| 缓存过期 | 缩短 TTL 后再请求失败端点 → 过期走占位数据 |
| 并发隔离 | 连续发送多个请求，各自独立取消、独立重试 |
| 页面卸载 | 发起请求后关闭/刷新标签页，Worker 立即终止 |
